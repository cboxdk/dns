# Cookbook

Short, complete recipes for the common tasks. Each uses the real API and can be
copy-pasted.

- **[Verify a domain](verify-a-domain.md)** — issue a token, tell the user where to
  put it, and confirm ownership authoritatively.
- **[Run a health check](run-a-health-check.md)** — diagnose a domain and act on the
  findings.
- **[Check propagation](check-propagation.md)** — tell "still rolling out" apart
  from "misconfigured".
